# Random Number Speaker

A simple web app that randomly announces numbers between 1-5 every 3 seconds for 2 minutes.

## Why I Made This

I made this app to go along with the finger numbering exercise in the beginning of Alfred's Basic Piano Libary Prep Course For Young Beginners Lesson Book Level A.

## Live Demo

🔗 [Try it here](https://lgivhan.github.io/random-number-speaker/)

## Features

- Speaks a random number (1-5) every 3 seconds
- Runs for exactly 2 minutes (40 announcements total)
- Visual display of current number
- Countdown timer
- Start/Stop controls

## How to Use

1. Click the **Start** button to begin the session
2. Listen as numbers are announced every 3 seconds
3. Click **Stop** anytime to end early
4. The session automatically stops after 2 minutes

## Technology

Built with vanilla HTML, CSS, and JavaScript using the Web Speech API.

## Local Development

Simply open `index.html` in your browser - no build process needed!
